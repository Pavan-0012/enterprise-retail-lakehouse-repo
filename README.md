# Enterprise Retail Lakehouse

## Overview

This project demonstrates the implementation of a production-inspired Retail Lakehouse using modern Data Engineering practices.

## Objectives

- Build scalable ETL pipelines with PySpark
- Implement Bronze, Silver, and Gold data layers
- Orchestrate workflows with Apache Airflow
- Store curated data in PostgreSQL and DuckDB
- Validate data quality
- Build analytical dashboards
- Automate testing and CI/CD

## Technology Stack

- Python
- PySpark
- DuckDB
- PostgreSQL
- Apache Airflow
- Docker
- dbt
- Great Expectations
- GitHub Actions
